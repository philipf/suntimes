# suntimes

A portable Go CLI that prints dawn, sunrise, sunset and dusk for a configured
location and date range, computed offline. See `docs/PRD.md` for requirements.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `philipf/suntimes`, managed with the `gh` CLI.
See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its name.
See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — one `CONTEXT.md` and `docs/adr/` at the repo root.
See `docs/agents/domain.md`.
